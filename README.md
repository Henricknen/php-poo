# php-poo

Repositório criado para **prática e estudo de Programação Orientada a Objetos (POO) em PHP**.

O objetivo é consolidar conceitos fundamentais da POO por meio de exemplos práticos, exercícios e correção de bugs, servindo também como material de apoio e portfólio profissional.

## 🧠 Conceitos praticados

- Criação de **classes**
- Definição de **atributos**
- Criação e uso de **métodos**
- **Encapsulamento**
- Uso de **modificadores de acesso** (`public`, `private`, `protected`)
- Construtores
- Organização de código orientado a objetos
- **Correção de bugs** e refatoração
- Boas práticas em PHP POO
